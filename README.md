# adityapandeycn.github.io

Source for [adityapandeycn.github.io](https://adityapandeycn.github.io), built with Jekyll on the [al-folio](https://github.com/alshedivat/al-folio) v1 starter and deployed by GitHub Actions.

- Home page: `_pages/about.md`
- Project write-ups: `_projects/`
- CV: `_data/cv.yml`
- Page styles: `assets/css/portfolio.css`

Run locally with `bundle install` and `bundle exec jekyll serve`. Layouts, includes and theme styles come from the al-folio gems, so they are not in this repo. See `AGENTS.md` before changing anything structural.
